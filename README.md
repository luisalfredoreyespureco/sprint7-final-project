# sprint7-final-project
Se realiza el análisis de datos para la empresa ConnectaTel y poder saber como utilizan los usuarios los servicios
El objetivo es poder entregar información para los Stakeholders sobre la forma en que los usuarios utilizan los servicios actualmente, realizando segmentaciones de edades y de volumen de utilización.
Se limpiaron los dataset antes de comenzar con el análisis.
Se quitaron centinels y se normalizaron algunas columnas.
Se verificaron outliers para diferentes columnas y se determinó que realizar en cada fase.
Se entrega informe ejecutivo donde se realiza sugerencia de realizar estudios de competencia y de propuestas de creación de nuevos planes tarifarios que permita el incremento del uso.
